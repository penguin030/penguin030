CASE 01 / VOC-BASED IMPROVEMENT

표준재무제표 / 문의 개선

월 30건+ → 약 1건

특정 연도가 조회되지 않는 문의가 반복됐습니다. OneClick 결과만 보지 않고 홈택스의 실제 조회 결과와 사용자 환경을 비교해 원인을 확인했습니다. 그 결과 ‘서면 제출 자료라 전자조회가 되지 않는 경우’와 ‘세무대리인 변경으로 이전 연도 조회가 제한되는 경우’를 별도 조건으로 구분했습니다.

해결 방식 / 빈도가 높았던 서면 제출 사례는 서비스 화면 안내 문구로 개선하고, 세무대리인 변경 사례는 CS 매뉴얼의 선확인 항목으로 정리했습니다.
기획 포인트 / 같은 증상이라도 원인을 나눈 뒤 모든 문제를 기능개발로 처리하지 않고 영향도와 빈도에 따라 해결 방식을 달리했습니다.
VOC → 재현 → 원천기관 비교 → 원인 분리 → 해결 방식 결정 → 결과 확인
